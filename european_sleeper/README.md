# European Sleeper Referral Code

![European Sleeper website with referral code input](input.png "European Sleeper website with referral code input")

## Description

This bookmarklet enhances the [European Sleeper website](https://europeansleeper.eu/) by adding input fields to enter discount/referral codes. It then redirects to the website using the entered code. If it is valid, discounts are applied accordingly. Otherwise, it has no effect.

Basically, it provides a more convenient way to redirect to https://europeansleeper.eu/referral?referralCode=<code\>.

## Usage

1. Go to https://europeansleeper.eu; change language as needed.
2. Execute the script; a new section titled "Referral code" should appear above the connection search (see screenshot above).
3. Enter a valid discount/referral code and click on "Apply Code" or hit enter.
4. You will be redirected to the website with the code applied. If it was a valid code, a note will show up above the connection search containing specific discount information.
